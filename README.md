# DSA Practice (C++)

My personal repository for Data Structures & Algorithms practice. It contains my solutions to LeetCode, Codeforces and other DSA problems, all written in **C++**.

## Repository Structure

```
DSA-Practice-C-/
├── Codeforces problems/      # Solutions to Codeforces problems
├── c++ dsa basics/           # C++ fundamentals and basic DSA concepts
├── 2nd Oct 2026 Leetode POTD.cpp
├── 3rd Oct 2026 LeetCode POTD.cpp
└── ...                       # More daily LeetCode POTD solutions
```

| Folder / File | What's inside |
|---------------|---------------|
| `Codeforces problems/` | Solutions to Codeforces problems |
| `c++ dsa basics/` | Basic C++ and DSA practice programs |
| `<date> LeetCode POTD.cpp` | LeetCode Problem of the Day solutions, one file per day |

## How to Run

Make sure you have a C++ compiler (like `g++`) installed.

```bash
# Compile
g++ -std=c++17 "filename.cpp" -o output

# Run
./output          # Linux / macOS
output.exe        # Windows
```
